## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e desenvolvedor web em formação. Gosto de construir projetos que unem tecnologia, criatividade e uma experiência de uso clara — desde sistemas de gestão até ferramentas para RPG, educação e inovação.

Atualmente, estou aprofundando meus conhecimentos em **TypeScript, React, Next.js, APIs, bancos de dados e arquitetura de aplicações**. Também tenho interesse em inteligência artificial, visão computacional, games e projetos que resolvem problemas reais.

- Desenvolvo interfaces responsivas e aplicações web completas.
- Trabalho com integração entre frontend, backend, APIs e banco de dados.
- Gosto de transformar requisitos em produtos funcionais e bem organizados.
- Aprendo continuamente por meio de projetos práticos.
